# CamWheel Manual Test Checklist

## 工具栏

- [ ] `CamWheel` 工具栏可见
- [ ] `物体穿透`、`视角对齐`、`构图辅助`、`设置` 四个按钮都正常显示
- [ ] 四个 SVG 图标在正常工具栏尺寸下可清晰区分

## 物体穿透

- [ ] 相机前方有群组/组件时，点击 `物体穿透` 后视角会跳到其后方
- [ ] 穿透后相机不会停在遮挡物内部
- [ ] 穿透后相机朝向保持稳定
- [ ] 前方无遮挡时给出轻提示且不报错

## 视角对齐

- [ ] 点击原始面后可对齐视角
- [ ] 点击群组/组件中的可见面后可对齐视角
- [ ] 对齐后自动进入两点透视
- [ ] 未命中有效面时不会报错

## 构图辅助

- [ ] 点击 `构图辅助` 后出现遮罩和参考线
- [ ] 再点一次可关闭构图辅助
- [ ] 默认横向比例为 `4:3`
- [ ] 默认竖向比例为 `3:4`
- [ ] 默认样式为 `九宫格`
- [ ] 右键菜单可切换 `九宫格 / 黄金分割 / 黄金螺旋 / 对角线`
- [ ] 右键菜单包含 SketchUp 原生 `保存视图`
- [ ] 保存视图并成功新增场景后弹出 `视角已保存`
- [ ] 导出图片成功后弹出 `图片已导出`
- [ ] 导出保存面板默认文件名为 `文件名-时间戳.jpg`
- [ ] `Ctrl` 可循环切换比例预设
- [ ] `Alt` 可循环切换构图样式

## 设置

- [ ] 点击 `设置` 可打开 HtmlDialog
- [ ] 比例、线型、颜色、透明度、穿透偏移可编辑
- [ ] 保存后当前视图立即刷新
- [ ] 关闭并重新打开 SketchUp 后设置仍然保留

## 拼图画布

- [ ] 点击 `拼图画布` 图标可打开新的 HtmlDialog
- [ ] 独立打开 `cam_wheel/web_canvas_tool/standalone.html` 也能运行
- [ ] 可上传多张图片并在左侧素材区看到缩略图
- [ ] 导入图片后默认留有明显排版空白，不会一上来贴满视野
- [ ] 画布支持拖拽平移和滚轮缩放
- [ ] 左键从空白处拖动可框选多张图片
- [ ] 左键按在未选中的图片上时会先选中该图并直接拖动
- [ ] 多张已选图片可整体移动
- [ ] 鼠标中键按在图片上时仍然只平移画布，不会拖动图片
- [ ] 选中图片后可修改位置、尺寸、旋转
- [ ] 图片可调整层级并删除
- [ ] 图片右键菜单包含 `图片切片 / 拖框裁剪 / 置顶一层 / 置底一层 / 删除图片`
- [ ] 多选图片时右键不会丢失当前多选，菜单会切换为 `导出选中 / 删除选中`
- [ ] 选中图片后画布会显示导出范围边界框，多选时边界框覆盖整体范围
- [ ] 靠近其他图片或网格时可触发吸附
- [ ] 吸附时会显示横线/竖线参考线，松手后参考线消失
- [ ] 选中图片后滚轮缩放会以选中区域中心为基准，不会把选中图片甩走
- [ ] 开启拖框裁剪后可在画布里的图片上拖出新的裁剪框
- [ ] 单选未旋转图片时可从属性区进入 `图片切片`
- [ ] 单张图片右键菜单可进入 `图片切片`
- [ ] 进入切片后普通属性区会收起，只显示当前切片模式相关控件
- [ ] 网格切片预览数量与 `行 x 列` 设置一致
- [ ] 切片预览只有 1 片时，`确认生成切片` 按钮保持禁用
- [ ] 确认网格切片后原图从画布移除，但仍保留在左侧素材区
- [ ] 参考线切片支持输入横竖线像素位置
- [ ] 参考线切片支持先点 `添加竖线/添加横线` 再到图片上直接落线
- [ ] 参考线切片支持直接拖动已有参考线手柄
- [ ] 切片确认后各切片会在原位置无缝拼回
- [ ] 切片后的图片仍可框选、移动和再次导出
- [ ] 单选未旋转普通图片时可点击顶部 `直线切割`
- [ ] 单张普通图片右键菜单可进入 `直线切割`
- [ ] 进入直线切割后普通属性区收起，只显示 `确认切割 / 取消`
- [ ] 进入直线切割后，鼠标移到图片上会预览待放置切线
- [ ] 默认单击图片会直接生成完整竖线
- [ ] 按住 `Shift` 单击图片会直接生成完整横线
- [ ] 已生成切线后可直接拖动整条线微调位置
- [ ] 按 `Esc` 可直接取消直线切割工具
- [ ] 无效切线时 `确认切割` 保持禁用，并提示当前切线无效
- [ ] 确认直线切割后原图从画布移除，并生成 2 个可独立选择的图片块
- [ ] 直线切割后的图片块可单独移动、旋转、删除和导出
- [ ] 直线切割后的图片块右键菜单不再出现 `直线切割 / 拖框裁剪 / 图片切片`
- [ ] 直线切割后的图片块导出结果与画布显示一致，且 `原图优先` 不会压缩源图像素密度
- [ ] 导出仅包含当前选中的图片，范围为选中图片外接矩形
- [ ] 导出倍率 `1x / 2x / 原图优先` 都能输出正确尺寸
