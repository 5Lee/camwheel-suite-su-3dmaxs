# CamWheel Manual Test Checklist

## 工具栏

- [ ] `CamWheel` 工具栏可见
- [ ] `物体穿透`、`视角对齐`、`构图辅助`、`设置` 四个按钮都正常显示
- [ ] 四个 SVG 图标在正常工具栏尺寸下可清晰区分

## 物体穿透

- [ ] 相机前方有群组/组件时，点击 `物体穿透` 后视角会跳到其后方
- [ ] 穿透后相机不会停在遮挡物内部
- [ ] 穿透后相机朝向保持稳定
- [ ] 前方无遮挡时给出轻提示且不报错

## 视角对齐

- [ ] 点击原始面后可对齐视角
- [ ] 点击群组/组件中的可见面后可对齐视角
- [ ] 对齐后自动进入两点透视
- [ ] 未命中有效面时不会报错

## 构图辅助

- [ ] 点击 `构图辅助` 后出现遮罩和参考线
- [ ] 再点一次可关闭构图辅助
- [ ] 默认横向比例为 `4:3`
- [ ] 默认竖向比例为 `3:4`
- [ ] 默认样式为 `九宫格`
- [ ] 右键菜单可切换 `九宫格 / 黄金分割 / 黄金螺旋 / 对角线`
- [ ] 右键菜单包含 SketchUp 原生 `保存视图`
- [ ] 导出图片成功后弹出 `图片已导出`
- [ ] 导出保存面板默认文件名为 `文件名-时间戳`
- [ ] `Ctrl` 可循环切换比例预设
- [ ] `Alt` 可循环切换构图样式

## 设置

- [ ] 点击 `设置` 可打开 HtmlDialog
- [ ] 比例、线型、颜色、透明度、穿透偏移可编辑
- [ ] 保存后当前视图立即刷新
- [ ] 关闭并重新打开 SketchUp 后设置仍然保留
