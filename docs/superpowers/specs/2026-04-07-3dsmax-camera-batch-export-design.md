# 3ds Max 相机读取与批量截图设计

## 背景

当前 3ds Max 插件已经支持：

- 当前活动视口导出
- 基于原生 `createPreview` 的 JPG 导出
- 默认文件名为场景名加时间戳
- 比例、分辨率、辅助线与单张导出控制面板

本次需要在 **3ds Max 插件** 内新增“读取场景相机并批量截图导出”的能力，同时不影响 SketchUp 插件与现有单张导出逻辑。

## 目标

- 在现有控制面板中增加相机读取与批量导出功能
- 以“面板勾选相机 → 选择一次导出文件夹 → 自动逐相机截图”的方式完成批量导出
- 保持现有原生导出路径、导出品质与渲染尺寸联动逻辑
- 面板以“加宽不加高”为原则，不破坏当前使用习惯

## 非目标

- 不新增相机缩略图预览
- 不新增相机分组或过滤器
- 不新增任务暂停 / 恢复 / 队列管理
- 不修改 SU 插件任何逻辑
- 不改变现有单张导出入口与主要行为

## 用户交互设计

### 面板布局

现有面板改为双列宽版布局：

- 左侧保留现有控制区
  - 比例预设
  - 分辨率设置
  - 快捷分辨率
  - 当前视口导出
  - 辅助线显示控制
  - 关于
- 右侧新增“相机批量截图”区
  - 相机多选列表
  - `刷新列表`
  - `全选`
  - `反选`
  - `批量导出选中相机`
  - 最近一次批量导出结果提示文本

约束：

- 优先增加宽度，不增加面板总体高度
- 相机列表区域使用固定高度列表控件，在既定高度内滚动

### 相机列表行为

- 打开面板时自动读取场景中的全部相机
- 用户点击 `刷新列表` 时重新扫描当前场景
- 列表项显示相机名称
- 用户通过勾选控制是否参与批量导出
- 支持一键 `全选` 与 `反选`
- 若场景中没有相机，列表为空，并在批量导出时给出提示

### 批量导出行为

- 点击 `批量导出选中相机`
- 若未勾选相机，提示“请先选择相机”
- 若已勾选相机，则弹一次文件夹选择框
- 用户选定目录后，插件按勾选顺序逐个导出
- 全部结束后弹出汇总提示：
  - 成功数量
  - 失败数量
  - 导出目录

## 导出执行设计

### 单个相机导出流程

对每一个被选中的相机，执行以下步骤：

1. 切换当前活动视口到该相机
2. 记录当前辅助线显示状态
3. 临时隐藏插件辅助线叠加，避免出现在导出结果中
4. 调用现有原生 `createPreview` 导出逻辑
5. 恢复辅助线显示状态
6. 返回成功或失败结果

### 批量导出流程

1. 收集被勾选的相机
2. 请求一次导出文件夹
3. 逐相机生成目标文件名
4. 逐相机切换视口并导出
5. 统计成功与失败结果
6. 导出结束后汇总提示

### 文件命名

命名规则：

- `场景名-相机名.jpg`

重名处理：

- 如果目标路径已存在，则自动追加递增后缀
- 示例：
  - `场景名-相机名.jpg`
  - `场景名-相机名-2.jpg`
  - `场景名-相机名-3.jpg`

### 导出设置

批量导出沿用现有单张导出设置：

- 导出格式：`jpg`
- JPG 质量：`100`
- 视角流程：原生预览导出路径
- 范围：`0-0`
- 视角预设：`用户自定义`
- 视觉样式：`标准`
- 明暗处理：默认首选项

## 技术设计

### 代码改动范围

预计主要改动以下文件：

- `external/3dsmax_camwheel_viewport_export/panel.ms`
- `external/3dsmax_camwheel_viewport_export/export.ms`

如需注册少量入口或初始化逻辑，再最小范围调整：

- `external/3dsmax_camwheel_viewport_export/CamWheel_ViewportExport.ms`

### 建议新增函数

在 `export.ms` 中新增或补充：

- `CamWheel_GetSceneCameras()`  
  返回场景相机集合，供 UI 使用

- `CamWheel_SanitizeExportNamePart value`  
  清理场景名 / 相机名中的非法文件名字符

- `CamWheel_BuildBatchExportFilename cameraName`  
  生成 `场景名-相机名.jpg`

- `CamWheel_ResolveUniqueExportPath directory filename`  
  若重名则追加数字后缀

- `CamWheel_RequestBatchExportDirectory()`  
  选择导出目录

- `CamWheel_ExportViewportForCamera cameraNode exportPath`  
  负责切换视口、隐藏辅助线、调用原生导出并恢复状态

- `CamWheel_ExportSelectedCameras cameraNodes exportDirectory`  
  循环执行批量导出并返回统计结果

在 `panel.ms` 中新增或补充：

- 面板级全局状态：相机列表缓存、勾选状态缓存、批量结果提示
- `CamWheel_PanelRefreshCameraList()`
- `CamWheel_PanelSelectAllCameras()`
- `CamWheel_PanelInvertCameraSelection()`
- `CamWheel_PanelGetSelectedCameras()`
- 批量导出按钮事件处理

### 数据流

1. 面板打开
2. `panel.ms` 请求 `export.ms` 的相机列表函数
3. UI 渲染相机名称与勾选状态
4. 用户点击批量导出
5. `panel.ms` 读取勾选结果并请求导出目录
6. `export.ms` 按顺序执行逐相机导出
7. `export.ms` 返回结果摘要
8. `panel.ms` 展示汇总提示

## 错误处理

以下情况需要明确提示且不中断整体稳定性：

- 未选择任何相机
- 场景中不存在相机
- 用户取消文件夹选择
- 单个相机切换视口失败
- 单个相机导出失败
- 文件重名冲突

策略：

- 批量任务中单个相机失败时，仅记录失败并继续后续相机
- 仅在前置条件不满足时整体取消，例如未选相机或取消目录选择

## 兼容性与边界

- 仅支持当前场景中可枚举的相机对象
- 保持当前活动渲染尺寸逻辑不变
- 保持当前“导出时不带辅助线”的行为
- 保持现有单张导出完全可用
- 不影响现有右键菜单、工具栏入口与控制面板入口

## 验证计划

手动验证覆盖以下场景：

1. 场景内存在多个相机，勾选 2~3 个后成功批量导出
2. 使用 `全选` 与 `反选` 后导出结果正确
3. 无相机场景点击批量导出时提示正确
4. 未勾选相机时提示正确
5. 取消选择导出目录时不执行导出
6. 目标目录存在重名文件时自动追加后缀
7. 批量导出的图片不带插件辅助线
8. 批量导出后单张导出仍可正常工作
9. 刷新列表后新增 / 删除相机可以正确反映到 UI

## 实施顺序建议

1. 先补导出层的相机枚举、路径生成与批量执行函数
2. 再调整面板为双列布局并接入列表交互
3. 最后补提示文案与手动验证
