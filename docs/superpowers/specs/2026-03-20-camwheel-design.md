# CamWheel / 构图辅助仪 设计文档

## 1. 项目概述

- 插件英文名：`CamWheel`
- 插件中文名：`构图辅助仪`
- 类型：SketchUp 相机辅助插件
- 运行环境：兼容 SketchUp 内置 `Ruby 2.7` 与 `Ruby 3.2`
- 目标平台：`macOS` / `Windows`
- 开发语言：`Ruby`

本插件第一版聚焦于建模过程中的相机操作与构图观察，不改动模型数据结构，不依赖复杂面板工作流。核心目标是通过三个独立工具按钮，提高复杂模型中的观察、对齐与构图效率，并通过一个设置按钮统一管理插件参数。

## 2. 第一版功能范围

### 2.1 物体穿透

用于将当前视角沿相机前向穿过前方第一个遮挡物，快速把视角移动到障碍物后方。

要求：

- 用户点击按钮后立即执行
- 沿当前相机视线方向检测前方第一个遮挡物
- 相机整体前移到该遮挡物之后
- 相机最终位置必须保证不落在物体内部
- 不隐藏对象，不修改对象，不进入群组编辑上下文

### 2.2 视角对齐

用于实现增强版“对齐视角”。

要求：

- 用户点击按钮后进入拾取状态
- 支持命中群组/组件的可见外表面语义
- 若可直接复用 SketchUp 原生“对齐视角”能力则优先复用
- 若无法直接调用，则自行实现与原生效果一致的相机对齐逻辑
- 对齐完成后自动切换为两点透视

### 2.3 构图辅助

用于在建模视口上方绘制遮罩与构图参考线，帮助观察画面比例与构图。

要求：

- 点击按钮后开启/关闭持续显示的构图叠加层
- 默认线型为九宫格
- 右键菜单可切换构图样式
- `Ctrl` 用于切换比例预设
- `Alt` 用于切换构图样式
- 视口横竖变化时自动适配

支持的构图样式：

- 九宫格
- 黄金分割
- 黄金螺旋
- 对角线

### 2.4 设置

提供一个单独的设置按钮，打开 `HtmlDialog`。

第一版设置项：

- 比例预设
- 自由比例宽高输入
- 构图线型
- 线条颜色
- 线条粗细
- 遮罩颜色
- 遮罩透明度
- 穿透安全偏移
- 视角对齐自动两点透视开关

## 3. 比例与默认行为

### 3.1 比例预设

支持以下比例：

- 自由
- 1:1
- 4:3
- 3:2
- 16:9
- 9:16
- 2.35:1

其中“自由”比例提供两个输入框，分别输入宽与高。

### 3.2 默认比例

- 横向视口默认构图比例：`4:3`
- 竖向视口默认构图比例：`3:4`

### 3.3 默认构图样式

- 默认显示：`九宫格`

## 4. 交互设计

### 4.1 工具入口

插件提供四个独立按钮：

- 物体穿透
- 视角对齐
- 构图辅助
- 设置

不设计复杂主界面，不使用额外常驻 UI 面板。

### 4.2 物体穿透交互

- 点击按钮
- 读取当前活动视图相机
- 沿前向做射线检测
- 找到首个遮挡体及其穿出位置
- 将相机 `eye` 与 `target` 整体推进到障碍物后方安全区

交互原则：

- 无动画过渡，直接跳过
- 若未命中遮挡体，则不改变相机，仅给轻提示

### 4.3 视角对齐交互

- 点击按钮后进入拾取
- 鼠标悬停时识别目标面或目标面的替代定位语义
- 点击后执行对齐
- 自动切换两点透视
- 完成后退出该工具

### 4.4 构图辅助交互

- 点击按钮：开启构图辅助
- 再次点击：关闭构图辅助
- 开启后，所有普通导航过程中持续显示构图叠加
- 右键菜单切换样式或打开设置
- `Ctrl` 循环切换比例预设
- `Alt` 循环切换构图样式

## 5. 架构设计

按“入口层 / 编排层 / 领域层 / 交互层 / 数据层”拆分：

### 5.1 建议目录结构

```text
CamWheel.rb
cam_wheel/
  extension.rb
  version.rb
  constants.rb
  main.rb
  tools/
    penetration_tool.rb
    align_view_tool.rb
    composition_overlay_tool.rb
  services/
    camera_service.rb
    composition_service.rb
  graphics/
    overlay_renderer.rb
  ui/
    settings_dialog.rb
    ui_bridge.rb
  data/
    settings_store.rb
  assets/
    icons/
      penetration.svg
      align_view.svg
      composition.svg
      settings.svg
```

### 5.2 入口层

- `CamWheel.rb`：仅做扩展注册
- `cam_wheel/extension.rb`：仅做加载入口
- `cam_wheel/version.rb`：维护版本与插件常量

### 5.3 编排层

- `cam_wheel/main.rb`：统一创建命令、工具栏、菜单、设置窗口并注入依赖

### 5.4 领域层

- `camera_service.rb`
  - 相机前向推进
  - 相机对齐到目标面
  - 两点透视切换
- `composition_service.rb`
  - 比例预设解析
  - 构图样式循环切换
  - 当前视口构图框计算

### 5.5 交互层

- `penetration_tool.rb`：一次性执行穿透逻辑
- `align_view_tool.rb`：拾取目标并调用相机对齐
- `composition_overlay_tool.rb`：管理构图辅助开启状态、右键菜单和快捷键
- `ui_bridge.rb`：作为 Ruby 与 `HtmlDialog` 的唯一通信桥接

### 5.6 绘制层

- `overlay_renderer.rb`：只负责计算和绘制遮罩与参考线，不负责状态决策

### 5.7 数据层

- `settings_store.rb`：统一读写插件设置
- 第一版使用 `Sketchup.read_default` / `Sketchup.write_default`

## 6. 技术实现重点

### 6.1 物体穿透

实现原则：

- 从 `view.camera` 获取 `eye` 和 `target`
- 计算前向单位向量
- 使用 `model.raytest` 找到首个命中
- 继续求穿出该首个遮挡体后的落点
- 在落点基础上增加安全偏移
- 若仍有落在实体内部的风险，则继续前推微调，直到确认停在外部

硬性要求：

- 最终相机不得停留在物体内部

### 6.2 视角对齐

实现原则：

- 使用 `InputPoint` / `PickHelper` 进行拾取
- 优先拿真实面的法线与位置
- 对群组/组件场景，尽量识别外表面语义
- 无法直接调用原生对齐时，自行计算 `eye / target / up`
- 自动切换两点透视

### 6.3 构图辅助绘制

实现原则：

- 基于当前视口像素尺寸计算内框矩形
- 用前景 2D 绘制叠加遮罩与参考线
- 构图绘制不依赖模型坐标
- 构图样式绘制算法独立于工具逻辑

建议：

- 将构图几何计算做成纯计算逻辑，输入视口尺寸和样式，输出遮罩与线段数据

- `composition_style`
- `overlay_line_color`
- `overlay_mask_color`
- `overlay_mask_alpha`
- `overlay_line_width`
- `align_enable_two_point_perspective`
- `penetration_offset`

设置命名空间统一使用：

- `CamWheel`

## 8. SVG 图标需求

需要为以下四个命令设计独立 SVG 图标：

- `物体穿透`
- `视角对齐`
- `构图辅助`
- `设置`

要求：

- 适合 SketchUp 工具栏显示
- 线条清晰、轮廓明确
- 同一视觉语言，便于形成统一插件识别

## 9. 兼容性与稳定性要求

- 兼容 `Ruby 2.7` 与 `Ruby 3.2`
- 路径处理兼容 `macOS` / `Windows`
- 不使用超出 Ruby 2.7 的语法特性
- 资源路径统一使用 `File.join`
- 所有用户可见失败都提供清晰提示

## 10. 第一版验收标准

- 插件可正常加载
- 四个按钮可显示并正常执行
- SVG 图标可在工具栏中正常显示
- 物体穿透后相机不会停留在物体内部
- 视角对齐可对群组/组件外表面语义生效
- 构图辅助可持续显示并支持右键切换与快捷切换
- 设置变更可立即生效并可持久保存
