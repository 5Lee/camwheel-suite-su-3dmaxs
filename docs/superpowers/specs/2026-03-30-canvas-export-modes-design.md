# CamWheel 拼图画布导出模式调整设计

## 目标
- 去掉导出倍率选择，统一按原图尺寸导出。
- 支持两种导出方式：
  - 选中图片合并导出
  - 选中图片逐张导出
- 保持现有 JPG / PNG 格式选择。

## 方案

### UI 调整
- 删除顶部工具栏中的 `1x / 2x / 原图优先` 下拉框。
- 将单一 `导出` 按钮改成两个按钮：
  - `合并导出`
  - `逐张导出`
- 右键菜单中的 `导出选中` 保持存在，默认执行“合并导出”。

### 导出行为
- 所有导出统一走原图尺寸布局，不再保留显示倍率导出。
- 合并导出：
  - 按当前选中图片的排版关系生成一张合成图。
  - 输出尺寸基于原图像素与当前排版关系计算。
- 逐张导出：
  - 遍历当前选中的每一张图片。
  - 每张图片单独导出为一个文件。
  - 切片后的 `polygon-image` 也按当前裁剪/切割后的原图区域导出。

### 文件命名
- 合并导出继续使用统一文件名，例如 `camwheel-selection.jpg` / `png`。
- 逐张导出使用：
  - 原文件名主体
  - 序号
  - 当前格式后缀
- 例如：`xxx-01.jpg`

## 风险
- 浏览器逐张导出会连续触发多次下载，属于预期行为。
- 多张切片名称可能相同，因此逐张导出必须追加序号。

## 测试重点
- 顶部不再显示导出倍率控件。
- 顶部存在合并导出和逐张导出按钮。
- 合并导出和逐张导出都有独立入口。
- 导出布局统一走原图尺寸。
