# CamWheel 拼图画布图片切片设计

## 目标
- 在现有拼图画布工具中新增“图片切片”能力。
- 同时支持：
  - 网格切片
  - 参考线切片
- 切片结果直接生成到当前画布中，作为多个独立图片块参与后续排版。
- 原图不再占用画布位置，但保留在左侧素材区，方便重复切片。

## 范围

### 本次范围
- 仅对单张已选图片开启切片。
- 新增两个入口：
  - 右侧属性区 `图片切片`
  - 画布图片右键菜单 `图片切片`
- 切片模式支持：
  - `网格切片`
  - `参考线切片`
- 参考线支持：
  - 在图片上直接添加/拖动
  - 在右侧输入像素位置列表
- 切片确认后：
  - 从画布移除原图 item
  - 保留素材区原图卡片
  - 生成多个新切片 item
  - 新切片默认在原位置无缝拼回

### 不在本次范围
- 自由形状切片
- 斜切或曲线切片
- 切片后自动散开排布
- 切片结果分组管理
- 切片结果重新合并成单张图
- 对已旋转图片直接切片

## 交互方案

### 进入切片
- 只有单选图片时允许进入切片模式。
- 若当前图片旋转不为 `0`，入口可见但不可执行，提示“切片前请先将旋转恢复为 0 度”。
- 右键菜单仅在单张图片节点上显示 `图片切片` 项；空白区域和多选状态不显示。
- 右键点击和属性区点击最终都进入同一套切片面板与状态流程。

### 切片编辑态
- 切片是独立于裁剪模式的单图编辑态。
- 进入切片态后：
  - 当前图片停止普通拖拽
  - 左键优先用于编辑网格/参考线
  - 鼠标中键仍然只做画布平移
- 右侧属性区切换为切片面板，原普通属性先收起。
- 切片态只修改临时 `sliceDraft`，不立即改原图 item。

### 网格切片
- 首版以 `行 x 列` 为主入口。
- 面板提供：
  - `行`
  - `列`
  - 预计生成切片数量提示
- 预览时在当前图片有效裁剪区域上叠加网格线。
- 若宽高不能整除：
  - 最后一列吸收宽度余数
  - 最后一行吸收高度余数
- 不丢像素，不留空白。

### 参考线切片
- 面板提供两组输入：
  - `竖线位置`
  - `横线位置`
- 输入格式为逗号分隔像素值，例如 `500,1200,1800`。
- 画布上允许直接加线并拖动调整。
- 参考线以当前图片“有效 crop 像素空间”为坐标基准，而不是画布显示坐标。
- 所有线进入最终计算前都要：
  - 限制在有效范围内
  - 排序
  - 去重
- 切片矩形由横向分段和纵向分段交叉组成。

### 切片确认结果
- 点击 `确认生成切片` 后：
  - 原图 item 从画布移除
  - 原图素材卡片保留
  - 根据切片矩形生成多个新 item
- 新 item 默认在原图位置无缝拼回，不自动打散。
- 新 item 与普通图片 item 一致，可继续：
  - 单独拖动
  - 框选
  - 组合移动
  - 裁剪
  - 导出

### 取消
- 点击 `取消` 后退出切片态，不修改原图画布状态。

## 状态与数据设计

### 新增前端状态
- `sliceMode: boolean`
- `sliceDraft: null | { itemId, mode, grid, guides, previewRects }`

### sliceDraft 建议结构
```js
{
  itemId: "item-123",
  mode: "grid" | "guides",
  grid: {
    rows: 2,
    cols: 3
  },
  guides: {
    vertical: [500, 1200],
    horizontal: [320, 880]
  },
  previewRects: [
    { x: 0, y: 0, width: 500, height: 320 }
  ]
}
```

### 切片 item 生成策略
- 不生成新的真实图片文件。
- 切片仍复用同一张源图 `src`。
- 每个切片 item 通过以下字段体现差异：
  - `crop`
  - `x`
  - `y`
  - `width`
  - `height`
- 这样现有导出、框选、原图优先导出链路都能复用。

## 计算规则

### 切片基准区域
- 所有切片都基于当前图片的有效裁剪区域：
  - `crop.x`
  - `crop.y`
  - `crop.width`
  - `crop.height`
- 也就是说，先裁剪再切片时，切的是裁剪后的那块区域。

### 网格转矩形
- 假设有效区域大小为 `crop.width x crop.height`。
- 列宽和行高按整数分配：
  - 常规格子用基础宽高
  - 最后一列/行吸收余数
- 最终得到一组 `previewRects`。

### 参考线转矩形
- 边界集合：
  - 横向：`[0, ...verticalGuides, crop.width]`
  - 纵向：`[0, ...horizontalGuides, crop.height]`
- 相邻边界之间组成一个矩形分段。
- 宽或高为 0 的分段直接丢弃。

### 从切片矩形生成画布 item
- 对每个矩形：
  - 新 `crop.x = item.crop.x + rect.x`
  - 新 `crop.y = item.crop.y + rect.y`
  - 新 `crop.width = rect.width`
  - 新 `crop.height = rect.height`
- 显示尺寸按原图当前显示比例换算：
  - `displayScaleX = item.width / item.crop.width`
  - `displayScaleY = item.height / item.crop.height`
  - `newWidth = rect.width * displayScaleX`
  - `newHeight = rect.height * displayScaleY`
- 位置按原图左上角递推：
  - `newX = item.x + rect.x * displayScaleX`
  - `newY = item.y + rect.y * displayScaleY`
- 这样切完后能无缝拼回原来的显示结果。

## UI 结构调整

### HTML 钩子
- 两个入口页都新增：
  - 切片入口按钮
  - 切片面板区域
  - 参考线输入字段
  - 确认/取消按钮
  - 右键菜单容器

### 右侧切片面板
- 顶部：
  - `网格切片`
  - `参考线切片`
- 网格模式字段：
  - `行`
  - `列`
- 参考线模式字段：
  - `竖线位置`
  - `横线位置`
  - `清空竖线`
  - `清空横线`
- 底部动作：
  - `确认生成切片`
  - `取消`

### 画布预览
- 网格模式显示叠加网格线。
- 参考线模式显示横竖切线和拖动手柄。
- 预览只在当前切片图片上显示，不影响其他 items。

## 与现有功能的关系

### 与裁剪模式
- 切片模式与裁剪模式互斥。
- 进入切片时自动退出裁剪模式。
- 进入裁剪时若仍处于切片态，则需先取消切片。

### 与多选/框选
- 多选状态不可进入切片。
- 切片确认后，新切片 items 可被正常框选和整体移动。

### 与导出
- 切片生成的 items 本质上仍是普通 item。
- 导出逻辑不做特殊分支。
- `原图优先` 仍按每个切片自身 crop 原始像素参与导出。

### 与中键平移
- 保持当前规则不变。
- 即使切片态下鼠标落在图片或参考线上，中键仍然只平移画布。

## 测试策略

### 结构测试
- 两个 HTML 入口都包含：
  - 切片入口
  - 切片面板钩子
  - 右键菜单钩子
  - 参考线字段
- JS 中包含：
  - 切片状态钩子
  - 网格矩形构建函数
  - 参考线矩形构建函数
  - 切片 item 生成函数

### 行为测试
- 单选时可进入切片，多选时不可进入。
- 旋转不为 0 的图片不可切片。
- 网格切片后生成正确数量的 item。
- 参考线输入后生成正确切片矩形。
- 参考线排序、去重和越界裁剪正确。
- 原图从画布消失但仍在素材区存在。
- 切片结果位置与尺寸能无缝拼回原图。
- 切片结果仍可框选、拖动和导出。

### 手测重点
- 属性区入口和右键入口都可进入同一切片面板。
- 切片态下中键仍只平移画布。
- 参考线拖动与输入互相同步。
- 网格预览与最终结果一致。
- 参考线预览与最终结果一致。
- 切片后 `1x / 2x / 原图优先` 导出行为保持正确。

## 风险与约束
- 右键菜单是本工具新增交互，需要避免影响现有左键拖动与框选事件。
- 参考线拖动、输入同步和中键平移同时存在，事件优先级需要明确。
- 若后续要支持旋转切片，当前基于轴对齐矩形的生成逻辑需要单独扩展。
