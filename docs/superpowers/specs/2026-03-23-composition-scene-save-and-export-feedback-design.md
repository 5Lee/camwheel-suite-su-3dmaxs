# CamWheel 构图辅助场景保存与导出反馈设计

## 目标
- 在 `构图辅助` 工具激活时，右键菜单增加一个 SketchUp 原生的“保存视图”入口，用于把当前视角保存成场景。
- 构图图片导出成功后，除状态栏提示外，再弹出明确的成功提示框。
- 导出图片的默认文件名改为“模型文件名 + 时间戳”，降低重复命名覆盖风险。

## 方案

### 右键菜单中的原生保存视图
- 在 `CompositionOverlayTool#getMenu` 中新增 `保存视图` 菜单项。
- 该菜单项不自行创建场景，而是转发到 SketchUp 原生命令，保持与用户熟悉的场景保存行为一致。
- 若当前环境不支持该原生命令，则静默忽略，不影响构图辅助其它菜单项。

### 导出成功反馈
- 维持现有状态栏文案。
- 当 `ExportService.export_current_view` 返回成功后，工具层额外调用 `UI.messagebox("图片已导出")`。
- 用户取消保存面板时不弹窗，只保留取消状态提示。

### 默认文件名
- 默认文件名格式为 `模型文件名-YYYYMMDD-HHMMSS.png`。
- `模型文件名` 取自当前模型路径的 basename，不带扩展名。
- 若模型尚未保存或无法拿到有效文件名，则回退为 `camwheel-YYYYMMDD-HHMMSS.png`。
- 文件名生成逻辑集中放在 `ExportService`，避免 UI 层拼接文件名。

## 影响范围
- `cam_wheel/tools/composition_overlay_tool.rb`
  - 扩展右键菜单。
  - 导出成功后补充弹窗提示。
  - 封装对 SketchUp 原生命令的调用。
- `cam_wheel/services/export_service.rb`
  - 增加默认文件名生成逻辑。
  - 保持现有导出、裁切、保存流程不变。
- `test/cam_wheel/composition_overlay_tool_test.rb`
  - 增加右键菜单存在性与原生命令转发测试。
  - 增加导出成功弹窗测试。
- `test/cam_wheel/export_service_test.rb`
  - 增加默认文件名格式与未保存模型回退测试。
- `docs/manual-test-checklist.md`
  - 补充场景保存入口和导出提示相关手测项。

## 风险与约束
- SketchUp 原生命令字符串可能存在版本差异，因此调用逻辑需要做存在性保护。
- 时间戳格式使用到秒，已足够覆盖大多数连续导出场景；若同秒内重复导出，仍由保存面板最终确认路径。
- 这次改动不改变导出像素尺寸、构图裁切规则和图像编码参数。

## 测试
- 菜单测试验证 `保存视图` 出现在构图辅助右键菜单中。
- 动作测试验证点击 `保存视图` 时会转发到 SketchUp 原生命令。
- 文件名测试验证已保存模型时默认名带模型名和时间戳，未保存模型时回退到 `camwheel` 前缀。
- 交互测试验证导出成功弹出“图片已导出”，取消导出时不弹出。
