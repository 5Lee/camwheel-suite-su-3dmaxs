# CamWheel 内置拼图画布工具设计

## 目标
- 在 CamWheel 插件中新增一个独立工具图标，点击后打开内置网页工具。
- 网页工具提供“无限画布拼图”能力，支持上传多张图片并合并导出。
- 同一套前端代码同时支持：
  - SketchUp 内置 HtmlDialog 使用
  - 独立本地 HTML 直接打开使用

## 第一版范围
- 新增工具栏/菜单入口，用于打开拼图画布工具
- 支持多张图片上传
- 支持无限画布平移与缩放
- 支持单张图片：
  - 移动
  - 吸附到其他图片边线/中线
  - 吸附到画布网格
  - 缩放
  - 旋转
  - 层级调整（置顶/置底）
  - 删除
  - 矩形裁剪
- 支持左键框选多张图片
- 支持多张已选图片整体移动
- 支持导出合成图
- 支持插件内置版与独立本地版共用同一套核心前端代码

## 不在第一版范围
- 自动排版模板
- 图片切片
- 自由形状裁剪
- 项目持久化保存/恢复
- 云端存储或在线协作

## 总体方案

### 插件入口
- 在 `cam_wheel/main.rb` 中增加一个新的命令和工具栏图标，例如“拼图画布”。
- 该命令打开一个新的 `HtmlDialog`。
- 插件入口只负责打开窗口与提供必要的本地桥接，不承载拼图逻辑。

### 前端目录结构
- 新增独立前端目录，例如：
  - `cam_wheel/web_canvas_tool/index.html`
  - `cam_wheel/web_canvas_tool/standalone.html`
  - `cam_wheel/web_canvas_tool/canvas_tool.js`
  - `cam_wheel/web_canvas_tool/canvas_tool.css`
- `index.html` 用于 SketchUp HtmlDialog。
- `standalone.html` 用于双击本地打开。
- 两个入口共享同一套 `canvas_tool.js` 和 `canvas_tool.css`。

### UI 布局
- 顶部工具栏：
  - 上传图片
  - 导出
  - 导出倍率
  - 缩放比例显示
  - 重置视图
- 左侧面板：
  - 素材列表
  - 素材缩略图
- 中间主区域：
  - 无限画布
  - 图片元素拖拽与变换
  - 直角图片卡片显示
- 右侧属性面板：
  - 位置
  - 尺寸
  - 旋转
  - 层级按钮
  - 删除按钮
  - 裁剪模式入口

### 前端状态模型
- 前端维护一个文档状态：
  - `items`: 图片元素数组
  - `viewport`: 画布平移/缩放状态
  - `activeSelection`: 当前主选中元素
  - `selectedIds`: 当前多选元素集合
  - `marqueeSelection`: 左键框选中的临时矩形
- 每个图片元素至少包含：
  - `id`
  - `src`
  - `x`
  - `y`
  - `width`
  - `height`
  - `rotation`
  - `zIndex`
  - `crop`

### 图片处理
- 图片上传后以前端 `Image` / `Canvas` 数据驱动渲染。
- 图片在画布中默认保持直角显示，不额外添加圆角。
- 裁剪第一版采用矩形裁剪框：
  - 进入裁剪模式后，用户拖动裁剪框
  - 仅修改该元素的 `crop` 数据，不破坏原图
- 导出时统一按当前元素状态渲染到最终 canvas。

### 吸附行为
- 拖动图片时优先尝试吸附到其他图片的左/中/右、上/中/下参考线。
- 若未命中图片吸附，则回退到画布网格吸附。
- 默认沿用画布底纹节奏作为网格步长，减少视觉与交互不一致。
- 吸附仅影响拖动中的位置计算，不修改图片尺寸、旋转和裁剪数据。
- 多图整体移动时按所选图片的整体外接矩形做吸附。
- 命中吸附时显示可见参考线：
  - 命中横向时显示横线
  - 命中纵向时显示竖线
  - 若同时命中，则两条线同时显示
  - 拖动结束后参考线立即消失

### 画布导航行为
- 鼠标左键用于选中、拖动和框选：
  - 按在未选中的图片上时，先选中该图片并直接拖动
  - 按在已选中的图片上时，整体拖动当前已选图片
  - 按在空白处拖动时，直接拉出框选矩形
  - 单击空白处时，清空当前多选
- 鼠标中键按下后始终只做画布平移：
  - 无论指针压在图片上还是空白处
  - 不触发图片选中
  - 不触发图片拖动
- 这样把“导航”和“编辑”分离，减少误触。

### 导入后的默认视野
- 图片导入后默认以更保守的初始尺寸放入画布，不一开始就贴满当前视野。
- 留白目标采用“比当前明显更宽松，但不过度空”的中间策略，优先保证拖拽排版空间。
- 多张图片仍保留错位摆放，但每张图的初始占比会略小于当前版本。

### 导出
- 第一版导出按当前选中图片计算，不再固定导出整张画布。
- 导出范围为当前选中图片的外接矩形。
- 无选中图片时不允许导出。
- 导出倍率提供：
  - `1x`：按当前排版显示尺寸导出
  - `2x`：按两倍显示尺寸导出
  - `原图优先`：尽量按更高像素密度输出，但保持当前排版比例、旋转与裁剪效果
- 插件内置版：
  - 前端生成导出数据
  - Ruby 层弹出保存面板并写文件
- 独立本地版：
  - 直接用浏览器下载
- 第一版保留 JPG/PNG 两种导出格式能力，但默认可以优先给 JPG。

### 插件与前端边界
- Ruby 层负责：
  - 打开 HtmlDialog
  - 资源路径解析
  - 本地文件选择/保存桥接
- 前端负责：
  - 画布交互
  - 元素状态管理
  - 裁剪/变换/导出合成
- 保持“前端为主、插件桥接为辅”的边界，便于独立版复用。

## 建议实现路径
1. 先把工具入口和 HtmlDialog 打通
2. 再搭基础三栏布局和无限画布
3. 再做图片元素的移动/缩放/旋转/层级
4. 再补矩形裁剪
5. 最后接导出与独立版入口

## 测试策略
- Ruby 侧测试：
  - 新命令已注册
  - HtmlDialog 可打开
  - 资源路径解析正确
- 前端第一版建议：
  - 先做结构和桥接测试
  - 复杂拖拽/裁剪交互以手测清单补足
- 手测重点：
  - 插件内入口能打开
  - 独立 HTML 能直接运行
  - 多图上传、移动、缩放、旋转、层级、裁剪正常
  - 左键从空白处拖动可框选多张图片
  - 左键按在未选中的图片上时直接拖动该图片
  - 多张已选图片可整体移动
  - 中键按在图片上时仍然只平移画布
  - 图片拖近其他图片时能自动对齐
  - 单张图片拖动时能落到网格吸附点
  - 吸附时能看到横线/竖线参考线，松手后消失
  - 导入图片后初始留白比当前版本更宽松
  - 导出只包含当前选中的图片
  - `1x / 2x / 原图优先` 三种导出倍率结果正确

## 风险与约束
- HtmlDialog 中实现无限画布与裁剪交互，前端复杂度会明显提升。
- 若纯原生 JS 自己写完整交互，开发成本较高；实现时可优先选轻量依赖或保持第一版交互尽量简单。
- 独立 HTML 直开模式下，某些浏览器对本地文件访问有限制，因此资源组织和文件读取方式需要偏前端原生兼容方案。
