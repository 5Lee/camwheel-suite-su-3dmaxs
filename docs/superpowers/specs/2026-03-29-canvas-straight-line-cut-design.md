# CamWheel 拼图画布图片直线切割设计

## 目标
- 在现有拼图画布工具中新增“直线切割”能力。
- 用户可对单张图片画出一条直线，将图片切成 2 个可独立移动和旋转的片段。
- 切割结果继续参与现有画布排版与导出，且导出时保持原图像素质量。

## 范围

### 本次范围
- 仅支持对单张已选中的普通图片执行直线切割。
- 新增两个入口：
  - 顶部工具栏 `直线切割`
  - 单张普通图片右键菜单 `直线切割`
- 切割流程支持：
  - 默认单击生成完整竖线
  - `Shift + 单击` 生成完整横线
  - 生成后拖动整条线微调位置
- 确认切割后：
  - 原普通图片 item 从画布移除
  - 生成 2 个多边形图片片段 item
  - 两个片段默认保留在原位无缝拼回
- 切割后的片段支持：
  - 移动
  - 旋转
  - 导出
  - 删除
  - 层级调整

### 不在本次范围
- 自由手绘切割
- 曲线切割
- 一次切多刀
- 多张图片同时切割
- 已切片段再次直线切割
- 已切片段再次矩形裁剪
- 对已旋转图片直接进入直线切割

## 总体方案

### 独立模式
- 直线切割作为独立于普通编辑、矩形裁剪、图片切片的单图编辑模式。
- 进入该模式后，仅当前单张图片可编辑切线，其他画布 item 不参与交互。
- 模式内只改临时草稿状态，确认前不修改原 item。

### 多边形片段方案
- 不在切割确认时生成新的 jpg/png 文件。
- 切割后的两个结果都继续引用同一张源图与同一组原始裁剪数据。
- 每个片段通过“多边形轮廓 + 原图映射”描述自己的有效区域。
- 这样可以同时满足：
  - 切完仍原位拼回
  - 保持原图质量
  - 后续移动、旋转、导出可复用现有画布体系

## 入口与交互限制

### 可进入条件
- 当前只选中 1 张普通图片。
- 图片 `rotation = 0`。
- 当前不在矩形裁剪模式或图片切片模式。

### 不可进入时的处理
- 多选、未选中、已旋转图片、已是多边形片段时，不执行直线切割。
- 若用户触发了不可执行入口，给出轻提示，例如“直线切割仅支持单张未旋转图片”。

### 入口行为
- 工具栏入口始终可见，但仅在满足条件时可执行。
- 右键菜单入口只在单张普通图片节点上显示。
- 两个入口都进入同一套切割模式和同一份临时状态。

## 状态设计

### 新增前端状态
- `lineCutMode: boolean`
- `lineCutDraft: null | { itemId, orientation, offset, validity, preview, isDragging }`

### 建议状态流转
1. `idle`
   正常画布态
2. `lineCutReadyToPlace`
   已进入直线切割，等待单击生成完整切线
3. `lineCutAdjusting`
   切线已生成，允许拖动整条线微调
4. `confirm`
   用户确认后生成两个片段并退出模式

### lineCutDraft 建议结构
```js
{
  itemId: "item-123",
  orientation: "vertical",
  offset: 640,
  isDragging: false,
  validity: {
    isValid: true,
    reason: null
  },
  preview: {
    line: {
      orientation: "vertical",
      offset: 640
    },
    polygons: [
      [{ x: 0, y: 0 }, { x: 640, y: 0 }, { x: 640, y: 900 }, { x: 0, y: 900 }],
      [{ x: 640, y: 0 }, { x: 1200, y: 0 }, { x: 1200, y: 900 }, { x: 640, y: 900 }]
    ]
  }
}
```

## 数据模型

### 普通图片 item
- 保持当前普通图片 item 结构不变。

### 新增片段 item 类型
- 直线切割后新增 `polygon-image` 类型 item。
- 建议至少包含：
  - `id`
  - `type: "polygon-image"`
  - `sourceImageId`
  - `src`
  - `crop`
  - `polygon`
  - `x`
  - `y`
  - `width`
  - `height`
  - `rotation`
  - `zIndex`
  - `originalBounds`

### 字段语义
- `polygon`
  表示该片段在图片局部 crop 坐标系中的有效轮廓。
- `crop`
  继续沿用当前普通图片的裁剪区域，保证对原图像素映射一致。
- `originalBounds`
  记录该片段对应的原始像素包围盒，供“原图优先”导出阶段计算更准确的输出边界。

## 切割计算规则

### 坐标基准
- 切线与 polygon 计算都基于当前图片的有效 `crop` 局部坐标。
- 也就是说，若图片已做过矩形裁剪，则直线切的是裁剪后的有效区域。

### 生成结果
- 先把当前有效图片区域视为一个矩形 polygon。
- 只支持用一条完整竖线或完整横线去分割该矩形 polygon。
- 若成功得到 2 个有效 polygon，则预览有效。
- 这两个 polygon 在确认时转换为 2 个 `polygon-image` item。

### 有效切线规则
- 竖线必须落在图片有效宽度内部，不能贴最左或最右边。
- 横线必须落在图片有效高度内部，不能贴最上或最下边。
- 结果必须形成 2 个有效 polygon。
- 若任一侧面积过小，则视为无效。
- 面积阈值建议使用原有效区域面积的 `1%` 作为首版下限。

### 无效切线处理
- 不生成可确认的结果。
- 预览线显示为无效状态。
- `确认切割` 按钮禁用。
- 给出轻提示，例如“切线没有形成有效的两块区域”。

## 预览与渲染

### 模式内预览
- 鼠标移到图片上时，预览一条待放置的完整切线。
- 默认预览竖线。
- 按住 `Shift` 时，预览切换为横线。
- 单击后显示：
  - 一条完整切线
  - 切线两侧的片段预览
- 已生成切线后，可直接拖动整条线调整位置。

### 片段渲染策略
- 画布里不预先生成新的图片文件。
- 渲染每个 `polygon-image` 时：
  - 先按原图与 crop 关系取得源图内容
  - 再对该内容应用 polygon 裁剪
- 两个片段默认仍位于原位置，因此确认后视觉上仍能无缝拼回原图。

## 模式内交互规则

### 鼠标与键盘
- 左键：
  - 用于单击生成切线
  - 用于拖动整条切线
- 中键：
  - 始终只做画布平移
- 滚轮：
  - 保持当前画布缩放规则
- `Shift`：
  - 临时切换为横线放置
- `Esc`：
  - 取消本次直线切割并退出模式

### 与现有画布行为的关系
- 直线切割模式下暂停普通框选。
- 直线切割模式下暂停普通图片拖动。
- 直线切割模式下不进入普通右键菜单流程，右键直接取消当前切割并退出模式。
- 点击空白处、切换其他工具、关闭面板时，若已有草稿但未确认，统一按取消处理，不自动确认。
- 单击图片其它位置时，直接按新的点击位置重建切线。

## 确认后的结果行为

### 替换规则
- 点击 `确认切割` 后：
  - 原普通图片 item 从画布中移除
  - 新建 2 个 `polygon-image` item
  - 两个新 item 继承原图的层级关系，并占据原图对应位置

### 默认选中状态
- 确认后默认同时选中两个新片段。
- 这样用户可以立刻整体拖动，也可以继续点选单块单独编辑。

### 片段右键菜单
- 片段的右键菜单首版只保留：
  - `置顶一层`
  - `置底一层`
  - `导出图片`
  - `删除图片`
- 不显示再次裁剪、再次切割等入口。

## 导出策略

### 导出目标
- 导出逻辑继续支持当前拼图工具的选中项导出方式。
- `polygon-image` 作为一种新 item 类型参与导出。

### 1x / 2x
- `1x / 2x` 仍按当前画布排版显示尺寸计算导出总边界。
- 片段绘制时根据各自 polygon 做裁剪后再绘制到导出 canvas。

### 原图优先
- `原图优先` 时，不以当前画布显示尺寸作为最终像素来源。
- 需要按每个片段对应的原始像素区域去计算导出密度。
- 若多个片段来自 4K 原图，则导出时应按该 4K 原始像素映射参与合成，不因画布缩放被压缩。

### 输出质量
- 本功能不引入额外压缩步骤。
- 直线切割本身不改变当前导出格式选择逻辑，只要求片段导出保持原图质量。

## UI 调整

### 工具栏
- 新增 `直线切割` 按钮。
- 按钮始终显示；不满足条件时点击仅给出轻提示，不进入模式。

### 右键菜单
- 单张普通图片菜单新增 `直线切割`。
- 已切片段的右键菜单不显示 `直线切割`。

### 右侧面板 / 模式动作区
- 进入直线切割后显示模式专用动作区，至少包括：
  - `确认切割`
  - `取消`
- 普通属性区在该模式下收起，避免与模式专用动作混淆。

## 与现有功能的关系

### 与矩形裁剪
- 直线切割与矩形裁剪互斥。
- 进入直线切割前若在裁剪态，先退出裁剪态。
- 切割基于裁剪后的有效 crop 区域。

### 与图片切片
- 直线切割与现有图片切片互斥。
- 已切片生成的普通矩形块，本次范围一律不支持进入直线切割。
- `polygon-image` 片段首版不支持再进入图片切片。

### 与多选
- 多选状态不可进入直线切割。
- 切割完成后两个新片段可被正常多选、整体移动和导出。

## 测试策略

### 结构测试
- HTML 与前端结构中新增：
  - `直线切割` 工具入口
  - 单图右键菜单入口
  - 模式动作区钩子
  - 片段渲染状态钩子

### 核心逻辑测试
- 水平切线可把矩形图分成 2 个有效 polygon。
- 垂直切线可把矩形图分成 2 个有效 polygon。
- 斜向切线可把矩形图分成 2 个有效 polygon。
- 未穿过图片区域的切线为无效。
- 只切出极小角块的切线为无效。
- 确认后原图被替换成 2 个片段 item。
- 两个片段在默认状态下视觉上能无缝拼回原图。
- `原图优先` 导出时按原始像素参与合成，不受画布缩放压缩。

### 手测重点
- 工具栏入口和右键入口都能进入同一模式。
- 第一击、第二击、端点微调流程稳定。
- `Shift` 吸附到 `0 / 45 / 90 / 135` 正常。
- 中键平移、滚轮缩放在模式内仍正常。
- 无效切线不能确认，并有提示。
- 确认后两个片段可单独移动、整体移动、旋转、导出。
- 不破坏现有框选、裁剪、切片和拼图导出流程。

## 风险与约束
- 多边形片段引入后，导出链路需要从“仅矩形图片”扩展到“矩形 + 多边形图片”两类绘制分支。
- 模式态、右键菜单、框选与中键平移共存，事件优先级需要明确，避免误触。
- 首版限制为未旋转图片切割，是为了避免局部坐标和 polygon 映射复杂度在这一轮失控。
