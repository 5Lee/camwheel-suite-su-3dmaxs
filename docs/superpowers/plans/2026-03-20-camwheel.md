# CamWheel Implementation Plan

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the first release of the `CamWheel` SketchUp plugin with four toolbar commands: penetration jump, align view, composition overlay, and settings.

**Architecture:** Keep SketchUp entrypoints thin and put behavior into focused Ruby modules. Use pure Ruby services for math, ratio presets, and settings so they can be tested with Minitest, while SketchUp-only tool wiring is verified with manual smoke tests inside SketchUp.

**Tech Stack:** SketchUp Ruby API, Ruby 2.7/3.2 compatible code, HtmlDialog, SVG toolbar icons, Minitest for pure Ruby units

---

Reference spec: `docs/superpowers/specs/2026-03-20-camwheel-design.md`
