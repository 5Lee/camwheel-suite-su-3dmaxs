# 3ds Max Manual Test Checklist

- [ ] 工具栏按钮可触发 `导出当前视口`
- [ ] 右键菜单可挂出 `CamWheel` 子菜单
- [ ] CamWheel 子菜单已正常注册
- [ ] `CamWheel` 子菜单包含 `导出当前视口`
- [ ] `CamWheel` 子菜单包含 `显示/隐藏辅助线`
- [ ] `CamWheel` 子菜单包含 `打开面板`
- [ ] 独立小面板可通过 `CamWheel_ShowPanel()` 打开
- [ ] 删除状态文件 `camwheel_guides_state.ini` 后重新启动插件
- [ ] 辅助线首次默认关闭
- [ ] 重新打开面板时会记住上一次辅助线开关状态
- [ ] 使用宏命令切换辅助线后，重启仍会记住上一次状态
- [ ] 打开面板默认读取当前渲染设置
- [ ] 修改比例或宽高后自动同步到渲染设置
- [ ] 相机列表自动读取当前场景相机
- [ ] `刷新列表` 可重新读取新增 / 删除后的相机
- [ ] `全选` 可一次勾选全部相机
- [ ] `反选` 可切换当前勾选状态
- [ ] `批量导出选中相机` 在未勾选相机时会提示
- [ ] 导出目标为当前激活视口
- [ ] 导出流程走 3ds Max 原生预览抓取
- [ ] 原生预览抓取被限制为 `0-0` 单帧
- [ ] 视口风格优先尝试切到 `Standard`
- [ ] 默认文件名为 `场景名-时间戳.jpg`
- [ ] 未保存场景默认文件名为 `camwheel-YYYYMMDD-HHMMSS.jpg`
- [ ] 取消保存时直接结束，不弹出错误提示
- [ ] 导出成功后弹出 `图片已导出`
- [ ] 批量导出文件名为 `场景名-相机名.jpg`
- [ ] 批量导出重复执行时会生成重名后缀
- [ ] 批量导出过程中失败相机不会中断后续导出
- [ ] 批量导出结束后会弹出成功 / 失败统计
- [ ] 安装目录中会生成 `camwheel_guides_state.ini`
- [ ] 三分线可显示/隐藏
- [ ] 中心线可显示/隐藏
- [ ] 对角线可显示/隐藏
- [ ] 辅助线按当前输出比例限制在安全框内显示
